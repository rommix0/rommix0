Decompiling, emulating and porting classic text-to-speech engines so they run on modern systems.

## 🔊 About me

- 🛠️ Software developer experienced with **C** and **Python**, and now building with **Claude**
- 🔬 I reverse engineer old speech synthesis software and rebuild it as portable, buildable C
- 🎛️ I'm interested in formant synthesis (Klatt), DSP, and analysis-by-synthesis tools
- 💼 **Currently looking for work.** Feel free to reach out!

## 🗣️ Featured projects

### Decompiled speech engines

<table>
<tr>
<td width="50%" valign="top">

**[prose2000_reborn](https://github.com/rommix0/prose2000_reborn)**<br>
Speech Plus Prose 2000 (v1.1 and v3.4.1) decompiled to C. Builds as a dynamic library on Windows and Linux.

</td>
<td width="50%" valign="top">

**[DECtalk-DTC-01-Reborn](https://github.com/rommix0/DECtalk-DTC-01-Reborn)**<br>
The DECtalk DTC-01 decompiled to C and compiled into a dynamic library for use with other programs.

</td>
</tr>
<tr>
<td width="50%" valign="top">

**[First-Byte-ProVoice-Reborn](https://github.com/rommix0/First-Byte-ProVoice-Reborn)**<br>
First Byte's ProVoice engine (Monologue and Smooth Talker), decompiled.

</td>
<td width="50%" valign="top">

**[infovox-230-reborn](https://github.com/rommix0/infovox-230-reborn)**<br>
A decompiled version of Telia Promotor's Infovox 230 speech synthesizer.

</td>
</tr>
<tr>
<td width="50%" valign="top">

**[TruVoice](https://github.com/rommix0/TruVoice)**<br>
A command-line program for Centigram's TruVoice TTS speech synthesizer.

</td>
<td width="50%" valign="top">

**[DECtalk-DTC-01-SAPI5](https://github.com/rommix0/DECtalk-DTC-01-SAPI5)**<br>
Lets the DECtalk DTC-01 be used as a voice from any SAPI5 application on Windows.

</td>
</tr>
</table>
